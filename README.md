# smoking-analysis
This repository provides a simulation and data analysis toolkit based on the "Smoking" software originally published by Mahmood Ahmad (Zenodo DOI: https://doi.org/10.5281/zenodo.17095791).  It allows users to model and analyze smoking-related datasets and includes additional functions and scripts developed by [Ahmad, 2025].
